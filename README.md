# your-garden

Turn your GitHub contributions into a virtual garden, where each day grows from a tiny sprout into anything you want!

## Project structure

- `index.html` contains the page structure.
- `css/styles.css` contains the page styling.
- `js/app.js` contains the garden rendering and GitHub API logic.

Open `index.html` in a browser to use the app. An internet connection is needed to load GitHub profile and contribution data.
